HTML Elements Reference

HTML Inline Elements

Element Usage Description
<a> A link Used to create a clickable link on a page.
<img> An image Used to add an image to the website.
<span> An inline container Used to group elements: for example, to style them.
<em> Emphasize text Used to emphasize specific text in italics.
<i> Italic text Used to mark a word or phrase in italics.
<b> Bold text Used to bold a word or phrase.
<strong> Important text Used to mark a word or phrase bold and important.
<mark> Highlight text Used to highlight text.
<s> Strikethrough text Used to strikethrough a word or phrase.
<sub> Subscript Used to write text in in subscript or below letter: H2O.
<small> Small text Used to represent the small print of a document.
<address> Address Used to represent an address:
Villa del Rio Mactan
<cite> Textual citation Used for references: For more monsters, see The Monster Book of Monsters.
<sup> Superscript Used to write text in in superscript or above letter: X2 + Y2.
<q> Inline quotation Used to add quatation marks on a word or phrase.
<br> A line break Used as a forced line break. The text breaks there no matter what.
<wbr> A possible line break Used as an optional line break. The text only breaks if line is too long.
<time> Date Used to format the date. For example: published on 13-03-2026.
<code> Code format Used to represent code format which looks like this.
<audio> Audio Used to add audio.
<video> Video Used to add a video.

Element Usage Description
<p> A simple paragraph Used to create a paragraph.
<blockquote> An extended quotation Used to create an extended quotation.
Or so they say.
<details> Additional information Used to indicate that there is
additional information available.
.
<ul> An unordered list Used to create an ordered list with numbers.
<ol> An ordered list Used to create an unordered list with bullets.
<dl> A definition list Used to define specific items. example:
An item
item definition
<hr> A definition list Used to create a horizontal line between
words.
<h1>-<h6> Text Heading Used to represent six levels of section headings. <h1> is the highest section level and <h6> is the lowest.
